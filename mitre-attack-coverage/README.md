# MITRE ATT&CK Coverage Mapping

Track coverage claims with evidence, not checkmarks alone. A technique being listed in a rule's tags does not prove the technique is detected end-to-end.

## Workflow
1. Define the behavior and threat hypothesis.
2. Identify data sources and required fields.
3. Link the detection or hunt to an ATT&CK technique.
4. Record test evidence and environment scope.
5. Assign a status using `docs/status-definitions.md`.
6. Review gaps, false positives, dependencies, and ownership.

The initial CSV contains illustrative candidate mappings, not evidence of production coverage.
