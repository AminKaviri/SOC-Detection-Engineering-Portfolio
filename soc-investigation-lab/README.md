# SOC Investigation Lab

Templates for repeatable alert triage and evidence-led investigations. Use synthetic or explicitly authorized data only.

## Investigation principles
- Record the alert source, rule version, timestamps, and telemetry gaps.
- Separate observed facts from inferences and unverified hypotheses.
- Build an event timeline and pivot only on documented indicators.
- Assess scope, affected identities/assets, business context, and potential impact.
- Record disposition rationale, escalation, containment decisions, and follow-up actions.
- Sanitize reports before publication; remove internal identifiers and sensitive telemetry.

This is a documentation aid, not a substitute for approved organizational procedures or incident-command direction.
